# دليل تطبيق RideHail - بالعربية

## ما هو RideHail؟

**RideHail** هو تطبيق طلب سيارات (مثل Uber) مصمم خصيصاً للسوق السوري. التطبيق يركز على:
- **الأمان والثقة** قبل السرعة
- **الدفع النقدي** كخيار أساسي
- **العمل بدون إنترنت** عند الحاجة
- **الشفافية** في كل خطوة

---

## هيكل المشروع

المشروع يتكون من 4 أجزاء رئيسية:

### 1. **Backend (الخادم)**
- **الموقع**: `backend/`
- **التقنية**: Node.js + Express + PostgreSQL
- **الوظيفة**: معالجة طلبات الركاب، مطابقة السائقين، إدارة المدفوعات، قاعدة البيانات

### 2. **Rider App (تطبيق الراكب)**
- **الموقع**: `rider-app/`
- **التقنية**: React Native (Expo)
- **الوظيفة**: تطبيق للركاب لطلب السيارات ومتابعة الرحلة

### 3. **Driver App (تطبيق السائق)**
- **الموقع**: `driver-app/`
- **التقنية**: React Native (Expo)
- **الوظيفة**: تطبيق للسائقين لاستقبال الطلبات وإدارة الأرباح

### 4. **Admin Dashboard (لوحة التحكم)**
- **الموقع**: `admin-dashboard/`
- **التقنية**: React.js
- **الوظيفة**: لوحة تحكم للمديرين لإدارة السائقين والرحلات والإعدادات

---

## قاعدة البيانات

### الملفات الأساسية:
1. **`database/schema.sql`** - الجداول الأساسية (المستخدمين، السائقين، الرحلات، المدفوعات)
2. **`database/schema_nextgen.sql`** - ميزات متقدمة (الثقة، الأمان، المناطق الذكية)
3. **`database/schema_syria.sql`** - ميزات خاصة بسوريا (النقد، الأمان، الأزمات)

### الجداول الرئيسية:

#### **users** - المستخدمون (الركاب)
- معلومات المستخدم: الهاتف، الاسم، البريد الإلكتروني
- حالة التحقق

#### **drivers** - السائقون
- معلومات السائق: الهاتف، الاسم، رخصة القيادة
- الحالة: قيد الانتظار، موافق عليه، مرفوض، معلق
- الموقع الحالي (lat, lng)
- حالة الاتصال (متصل/غير متصل)

#### **vehicles** - المركبات
- معلومات السيارة: الماركة، الموديل، السنة، اللون، رقم اللوحة
- أنواع الرحلات المدعومة (اقتصادي، متميز، XL)

#### **trips** - الرحلات
- معلومات الرحلة: الراكب، السائق، نقطة الانطلاق، الوجهة
- الحالة: مطلوبة، مقبولة، السائق في الطريق، قيد التنفيذ، مكتملة، ملغاة
- السعر المقدر والنهائي
- طريقة الدفع (نقدي/بطاقة)

#### **payments** - المدفوعات
- معلومات الدفع: المبلغ، الحالة، طريقة الدفع
- ربط مع Stripe للدفع بالبطاقة

#### **wallets** - المحافظ (للسائقين)
- رصيد السائق
- الأرباح المتراكمة

#### **ratings** - التقييمات
- تقييم الراكب للسائق (1-5 نجوم)
- تعليقات

#### **trip_cash_records** - سجلات النقد (سوريا)
- المبلغ المتوقع
- المبلغ المستلم فعلياً
- تأكيد الاستلام

#### **safe_pickup_points** - نقاط الانطلاق الآمنة (سوريا)
- مواقع آمنة ومعروفة للانطلاق
- الاسم بالعربية والإنجليزية

#### **risk_zones** - مناطق الخطر (سوريا)
- مناطق محفوفة بالمخاطر
- مستوى الخطر (منخفض، متوسط، عالي، تجنب)

#### **crisis_events** - الأحداث الطارئة (سوريا)
- أحداث أزمات (طقس، أمن، أحداث)
- رسائل للركاب والسائقين
- إمكانية إيقاف الرحلات الجديدة

## الميزات الرئيسية

### للركاب (Rider App)

#### 1. **التسجيل والدخول**
- تسجيل برقم الهاتف
- التحقق برمز OTP (مرسل عبر SMS)
- لا حاجة لبريد إلكتروني

#### 2. **طلب رحلة**
- فتح الخريطة مباشرة عند فتح التطبيق
- تحديد نقطة الانطلاق والوجهة
- **اقتراحات آمنة** لنقاط الانطلاق
- عرض السعر المقدر قبل الطلب
- **قفل السعر** عند التأكيد (ضمن القواعد)
- زر واحد رئيسي: "اطلب رحلة"

#### 3. **مطابقة السائق**
- البحث عن أقرب سائق متاح
- عرض معلومات السائق:
  - الاسم والصورة
  - صورة السيارة
  - رقم اللوحة
  - **شارة موثّق** (إذا كان سائق موثوق)
  - التقييم
- متابعة حركة السائق على الخريطة

#### 4. **الأمان**
- **مشاركة الرحلة مع العائلة**: رابط مباشر لمتابعة الرحلة
- **طوارئ صامتة**: زر طوارئ لا يظهر على الشاشة (لحالات الخطر)
- **تتبع الرحلة**: مراقبة المسار
- **تأكيد الوصول بأمان**: زر "أكد وصولك بأمان" بعد انتهاء الرحلة

#### 5. **المدفوعات**
- **نقدي** (الخيار الأساسي)
- بطاقة (اختياري، عبر Stripe)
- عرض السعر قبل الرحلة
- إيصال بعد الرحلة

#### 6. **التاريخ والتقييمات**
- عرض جميع الرحلات السابقة
- تقييم السائق بعد كل رحلة
- عرض الإيصال

---

### للسائقين (Driver App)

#### 1. **التسجيل**
- تسجيل برقم الهاتف
- رفع الوثائق (رخصة القيادة)
- معلومات السيارة
- انتظار موافقة المدير

#### 2. **الاتصال/الانقطاع**
- زر للاتصال بالشبكة أو الانقطاع
- عند الاتصال: يبدأ استقبال الطلبات

#### 3. **استقبال الطلبات**
- عرض تفاصيل الرحلة:
  - نقطة الانطلاق والوجهة
  - السعر المقدر
  - **الأرباح المتوقعة** (قبل القبول)
- قبول أو رفض الرحلة
- **العمل بدون إنترنت**: يمكن قبول الرحلة حتى بدون اتصال (يتم المزامنة لاحقاً)

#### 4. **تنفيذ الرحلة**
- التنقل إلى نقطة الانطلاق
- زر "أنا في الطريق"
- زر "بدء الرحلة"
- التنقل إلى الوجهة
- زر "إنهاء الرحلة"

#### 5. **تأكيد استلام النقد**
- بعد إنهاء الرحلة: عرض "استلمت النقد؟"
- المبلغ المتوقع
- زر "تأكيد استلام المبلغ"
- يتم تسجيل المبلغ المستلم فعلياً

#### 6. **الأرباح**
- عرض رصيد المحفظة
- أرباح اليوم
- **الهدف اليومي** (مثل: "تبقى 50$ للهدف")
- تاريخ الرحلات والأرباح

#### 7. **المناطق الذكية**
- عرض مناطق الطلب المرتفع
- رسائل مثل: "طلب مرتفع في المنطقة X لمدة 45 دقيقة"

#### 8. **الإرهاق**
- تتبع ساعات العمل
- اقتراح أخذ استراحة بعد ساعات طويلة
- زر "أخذ استراحة 15 دقيقة"

### للمديرين (Admin Dashboard)

#### 1. **لوحة المعلومات**
- إجمالي الرحلات
- إجمالي الإيرادات
- العمولات
- السائقون النشطون

#### 2. **إدارة السائقين**
- عرض جميع السائقين
- الموافقة/الرفض على التسجيلات
- تعليق السائقين
- عرض الأرباح والرصيد

#### 3. **الرحلات**
- عرض جميع الرحلات
- الحالة (مطلوبة، قيد التنفيذ، مكتملة، ملغاة)
- التفاصيل الكاملة

#### 4. **التسويات النقدية** (سوريا)
- عرض المبالغ المتوقعة مقابل المستلمة لكل سائق
- حسب التاريخ
- متابعة الفروقات

#### 5. **مناطق الخطر** (سوريا)
- إضافة/تعديل مناطق الخطر
- تحديد مستوى الخطر
- إيقاف الرحلات في مناطق محددة

#### 6. **الأزمات** (سوريا)
- إعلان أزمة (طقس، أمن، أحداث)
- رسائل للركاب والسائقين
- إيقاف الرحلات الجديدة عند الحاجة

#### 7. **إعدادات الأسعار**
- تعديل الأسعار حسب نوع الرحلة (اقتصادي، متميز، XL)
- الأسعار الأساسية، لكل كيلومتر، لكل دقيقة

#### 8. **العمولات**
- تعديل نسبة العمولة (مثلاً 20%)
- عرض إجمالي العمولات

#### 9. **النزاعات**
- عرض النزاعات المفتوحة
- اقتراحات الذكاء الاصطناعي (في المراحل المتقدمة)
- حل النزاعات

## التقنيات المستخدمة

### Backend
- **Node.js**: بيئة تشغيل JavaScript
- **Express**: إطار عمل لبناء API
- **PostgreSQL**: قاعدة بيانات علائقية
- **Socket.io**: للاتصال الفوري (مثل متابعة موقع السائق)
- **JWT**: للتحقق من الهوية
- **Stripe**: للدفع بالبطاقة (اختياري)

### Mobile Apps (Rider & Driver)
- **React Native**: لبناء تطبيقات iOS و Android
- **Expo**: أداة لتسهيل التطوير والنشر
- **React Navigation**: للتنقل بين الشاشات
- **react-native-maps**: لعرض الخرائط
- **Socket.io Client**: للاتصال الفوري

### Admin Dashboard
- **React.js**: مكتبة JavaScript لبناء واجهات المستخدم
- **Vite**: أداة بناء سريعة
- **React Router**: للتنقل بين الصفحات
- **Axios**: لطلب البيانات من API

## كيف يعمل التطبيق؟

### تدفق طلب رحلة (من الراكب):

1. **الراكب يفتح التطبيق**
   - يظهر الخريطة مباشرة
   - تحديد موقع الراكب تلقائياً

2. **اختيار الوجهة**
   - الراكب يحدد نقطة الانطلاق (اقتراحات آمنة متاحة)
   - تحديد الوجهة
   - عرض السعر المقدر

3. **طلب الرحلة**
   - الضغط على "اطلب رحلة"
   - البحث عن أقرب سائق متاح
   - مطابقة السائق (خوارزمية: الأقرب + التقييم)

4. **مطابقة السائق**
   - عرض معلومات السائق
   - متابعة حركة السائق على الخريطة
   - إشعارات: "السائق في الطريق"، "سيصل خلال X دقائق"

5. **الرحلة**
   - السائق يبدأ الرحلة
   - متابعة المسار على الخريطة
   - إمكانية مشاركة الرحلة مع العائلة
   - زر طوارئ (صامت) متاح

6. **إنهاء الرحلة**
   - السائق ينهي الرحلة
   - حساب السعر النهائي
   - الدفع النقدي
   - تأكيد الوصول بأمان

7. **التقييم**
   - تقييم السائق (1-5 نجوم)
   - تعليق اختياري

---

### تدفق استقبال رحلة (من السائق):

1. **السائق يتصل بالشبكة**
   - الضغط على زر "متصل"
   - يبدأ إرسال الموقع كل بضع ثوان

2. **استقبال طلب**
   - إشعار بطلب جديد
   - عرض التفاصيل:
     - نقطة الانطلاق والوجهة
     - السعر المقدر
     - الأرباح المتوقعة

3. **قبول/رفض**
   - السائق يقرر القبول أو الرفض
   - يمكن القبول حتى بدون إنترنت (يتم المزامنة لاحقاً)

4. **التنقل**
   - التنقل إلى نقطة الانطلاق
   - إشعار الراكب: "السائق في الطريق"

5. **بدء الرحلة**
   - السائق يضغط "بدء الرحلة"
   - التنقل إلى الوجهة

6. **إنهاء الرحلة**
   - الوصول للوجهة
   - الضغط على "إنهاء الرحلة"
   - حساب السعر النهائي

7. **تأكيد النقد**
   - عرض "استلمت النقد؟"
   - المبلغ المتوقع
   - تأكيد الاستلام
   - تسجيل المبلغ المستلم

## الميزات الخاصة بسوريا

### 1. **الدفع النقدي أولاً**
- لا حاجة لبطاقة ائتمان
- تأكيد استلام النقد من السائق
- تسجيل المبالغ المتوقعة مقابل المستلمة

### 2. **العمل بدون إنترنت**
- يمكن طلب رحلة حتى بدون اتصال (يتم الإرسال عند الاتصال)
- يمكن قبول رحلة بدون اتصال
- يمكن إنهاء رحلة بدون اتصال

### 3. **الأمان المتقدم**
- **مشاركة مع العائلة**: رابط مباشر لمتابعة الرحلة
- **طوارئ صامتة**: زر لا يظهر على الشاشة
- **تأكيد الوصول بأمان**: إغلاق دائرة الأمان

### 4. **نقاط الانطلاق الآمنة**
- اقتراح مواقع آمنة ومعروفة
- تقليل الارتباك والخلافات

### 5. **مناطق الخطر**
- تحديد مناطق محفوفة بالمخاطر
- تحذير الركاب والسائقين
- إمكانية إيقاف الرحلات في مناطق محددة

### 6. **نظام الأزمات**
- إعلان أزمات (طقس، أمن، أحداث)
- رسائل واضحة للركاب والسائقين
- إيقاف الرحلات الجديدة عند الحاجة

### 7. **السائق الموثوق**
- برنامج للسائقين الموثوقين
- شارة "موثّق" في التطبيق
- معايير: الوثائق + السلوك + الاستمرارية

### 8. **اللغة العربية**
- واجهة بالعربية أولاً
- رسائل واضحة ومطمئنة
- مصطلحات مألوفة

## الأمان والثقة

### نظام الثقة
- **تقييم السائق**: ليس فقط النجوم، بل:
  - سلوك القيادة
  - سلوك الإلغاء
  - تقييمات الركاب
- **تقييم الراكب**: السائقون يرون تقييم الراكب أيضاً
- **السائقون السيئون**: يقل عدد مطابقاتهم تلقائياً

### الأمان
- **مشاركة الرحلة**: العائلة يمكنها المتابعة
- **طوارئ صامتة**: إبلاغ بدون إظهار على الشاشة
- **تتبع المسار**: مراقبة الانحرافات
- **تأكيد الوصول**: إغلاق دائرة الأمان

## كيفية التشغيل

### 1. قاعدة البيانات
```bash
# إنشاء قاعدة البيانات
createdb ridehail

# تشغيل الملفات بالترتيب
psql -d ridehail -f database/schema.sql
psql -d ridehail -f database/schema_nextgen.sql
psql -d ridehail -f database/schema_syria.sql
```

### 2. Backend
```bash
cd backend
cp .env.example .env
# تعديل .env وإضافة:
# - DATABASE_URL
# - JWT_SECRET
# - STRIPE_SECRET_KEY (اختياري)

npm install
npm run dev
```

### 3. Rider App
```bash
cd rider-app
npm install
# إعداد EXPO_PUBLIC_API_URL في .env أو في الكود
npx expo start
```

### 4. Driver App
```bash
cd driver-app
npm install
# إعداد EXPO_PUBLIC_API_URL
npx expo start
```

### 5. Admin Dashboard
```bash
cd admin-dashboard
npm install
# إعداد VITE_API_URL
npm run dev
```

## الخلاصة

- ✅ **الأمان والثقة** قبل كل شيء

- ✅ **العمل بدون إنترنت** عند الحاجة

التطبيق جاهز للاستخدام الأساسي ويمكن توسيعه حسب الحاجة.
